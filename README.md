# MEGAPOSTER · 分块滤镜出图

超大宣传画的分块渲染内核与出图任务面板。画面由矢量元素、透明 PNG 精灵和程序化纹理组成；滤镜链（高斯模糊 / 投影阴影 / 重采样）在**块内带邻域计算**，导出时裁掉邻域再拼装，因此换分块尺寸不会改变画面，也不会在块边界截断模糊或阴影。

## 启动界面

界面不是静态预览：所有控件由内核参数表 `/api/kernel` 生成，提交的任务由子进程节点渲染，结果从磁盘块缓存拼装。

```bash
npm install          # 仅 @napi-rs/canvas（Skia），首次执行
npm run assets       # 生成透明 PNG 精灵（已生成可跳过）
npm start            # 启动面板：http://127.0.0.1:4173
```

浏览器打开 **http://127.0.0.1:4173** 。环境变量：`PORT` 换端口，`HOST` 换监听地址，`WORKERS` 改工作节点数（默认 CPU 核数的 1/2，2–6）。

### 面板怎么用

1. 左侧「画幅与网格」选场景、宽高和分块边长（或点 64/128/256/512、「小样 / 展示 / 超大」预设）。
2. 「滤镜链」里的滑块和颜色控件全部来自内核描述；可叠加最多 6 个滤镜，顺序可上下调整。
3. 点「预演网格」：画布立即画出每块的**输出框（绿）**与**计算范围（暗黄，含邻域）**，右侧列出每块的计算尺寸与四边邻域。
4. 点「提交出图」：顶部进度随 SSE 事件推进；完成后画布显示拼接大图，叠加每块输出框与计算范围。
5. 结果页签给出与整幅参照的逐像素差、边界带（2px）误差、可并排对比的同区域裁剪，以及「对比不同网格」——把同一画面按 64/128/256/512 分别渲染，逐块边界带与整幅参照比较。
6. 「分块」页签的每一行可点击：画布缩放到该块，能放大检查接缝，虚线为它的实际计算范围。
7. 「内存」页签记录节点峰值 RSS、节点上限、导出一条带峰值、主进程 RSS、导出字节与缓存复用/渲染/重试块数。全部命中缓存时会标注峰值取自该作业的历史记录。
8. 「事件」页签记录重试与失败；在「故障演练」里填块号（如 `3,7`），这些块第一次执行会抛错，验证**只重做缺失块**。

## 设计要点

- **邻域回溯**：滤镜的几何支撑（模糊 `3·r`、阴影 `blurSupport+spread`、重采样反算角点）从输出块反推每块需要的计算矩形；工作节点只渲染这个矩形。
- **逐像素与分块无关**：模糊用零填充 + float64 前缀和，结果量化到 1/65536 网格；矢量元素在**自身 bbox 原点的局部画布**上栅格化成子块缓存（`PATCH=384`，`EDGE_PAD=10`），Skia 抗锯齿不随请求块变化。测试与基准里各网格对整幅参照的最大差均为 0。
- **全图坐标**：程序化噪声、网点、渐变、元素位置全部按文档坐标计算，改分块不产生图案重启。
- **有界内存**：节点不接收整幅像素；块缓存落盘为 `.bin`，拼装时一次只读一条水平带。节点内存上限是**强制执行**的：每个块渲染完先比对 `/proc` 里的峰值 RSS（VmHWM），超过 256MB 就判该节点失败，换新节点后只重排这一块。主进程和浏览器都不解码整张海报——查看器按可见窗口向 `/crop.png` 请求，缩放也是裁剪。
- **缓存键**：`kernel 版本 + 场景 id + 画幅 + 内容模式 + 归一化滤镜参数` 作为作业键，块文件再按块索引/裁剪/计算矩形区分；命中则完全不调度节点。
- **失败重做**：队列只包含缺失块，失败的块单条重排重试；节点进程死亡会替换为新节点，其余块继续。

## 证据记录

```bash
npm test                    # 块=参照、跨尺寸一致、重试、缓存、导出、内存上限、跨网格误差
node scripts/bench.js       # 跨网格边缘误差对照表（小样）
node scripts/bench.js --large --fresh   # 冷缓存跑受限内存大图，写入 .cache/bench-large.json
```

`--fresh` 用临时缓存从零渲染，时间/峰值来自真实计算；不加则复用缓存，数字反映的是命中路径。

最近一次记录（本机，4 节点，冷缓存）：12000×9000 / 512px / 432 块，渲染 25.8s，墙钟 42.9s，节点峰值 238.3MB（上限 256MB，按 VmHWM 强制，超出即判该块失败并换新节点重试），导出一条带峰值 24.4MB，主进程 RSS 203.6MB，输出 32.4MB PNG。原始 RGBA 需 412MB，任何进程都未整体持有。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/kernel` | 滤镜参数表、场景目录、限制；界面据此生成控件 |
| POST | `/api/preview` | 只算网格与每块计算范围 |
| POST | `/api/run` | SSE 任务流：`accepted`/`plan`/`tile`/`retry`/`failed`/`error`/`done` |
| POST | `/api/grids` | 同一画面多种分块的边缘误差对照 |
| GET | `/api/runs` | 已完成任务与内存记录 |
| GET | `/api/runs/:id/poster.png` | 导出的拼接大图 |
| GET | `/api/runs/:id/overview.png?w=` | 由块文件降采样出的总览（不解码整图） |
| GET | `/api/runs/:id/crop.png?x&y&w&h` | 局部像素，直接读相关块 |
| GET | `/api/runs/:id/refcrop.png?x&y&w&h` | 参照图同区域裁剪，用于并排比对 |

## 目录

```
src/kernel/     geometry 邻域回溯 · image 预乘表面/模糊 · filters 滤镜与参数表
                elements 局部栅格化子块 · scene 场景与程序化纹理 · pipeline 计划/渲染/比较
                scheduler 进程池/重试/缓存/流式导出 · worker 节点进程 · png 编解码
src/server/     HTTP + SSE，内核描述驱动界面
src/ui/         任务面板（原生 JS，无构建）
assets/         透明 PNG 精灵
tests/          node:test 用例
scripts/        资产生成、基准与记录
```
